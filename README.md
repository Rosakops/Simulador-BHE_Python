## 📌 Description

A computational simulation environment developed to model the transport and permeability of **functionalized nanocarriers** across the **blood-brain barrier (BBB)**, specifically targeted at therapies for **Multiple Sclerosis**.

The simulator evaluates key biophysical variables, such as glycocalyx interactions, capillary hemodynamics, and receptor-mediated transcytosis mechanisms, to predict drug delivery efficiency to the central nervous system.

## 🚀 How to Run

The route to access the simulator is `/web/index.html`. Then open the file in your browser.
